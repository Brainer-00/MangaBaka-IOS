## About

**MangaBaka iOS** is an unofficial, community-maintained iOS build of the open-source MangaBaka application.

This project is maintained by [Brainer-00](https://github.com/Brainer-00) and focuses on providing reliable iOS builds, sideloading support, iOS-specific fixes, release automation, and documentation.

The application is based on the original open-source [MangaBaka App](https://github.com/Oazzies/MangaBaka-App) by [Oazzies](https://github.com/Oazzies).

> This project is not an official MangaBaka release and is not affiliated with or endorsed by MangaBaka or the original project maintainers.

## Current Status

The iOS application currently builds and runs successfully as an unsigned IPA suitable for sideloading.

OAuth account login is still being configured for this iOS distribution.

## Installation

Prebuilt unsigned IPA releases will be provided through this repository once the first public iOS release is ready.

For now, development builds can be installed using tools such as **Sideloadly**, with AltStore and SideStore support planned.
